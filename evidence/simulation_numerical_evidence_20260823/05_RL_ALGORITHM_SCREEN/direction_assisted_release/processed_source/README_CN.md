# 方向辅助、体积策略强化学习对照包

这个实验按照真实部署中的控制分工重新比较强化学习算法：神经网络只选择加液体积，程序根据当前 pH 和目标 pH 统一决定加酸或加碱。

## 实验究竟比较什么

- 神经网络输入：当前 pH、目标 pH、pH 变化、当前 pH 减目标 pH、上一次加液体积。
- 神经网络输出：0.01-10.00 mL，共 1,000 个体积类别。
- 外部方向规则：`current_pH < target_pH` 时加碱，否则加酸。
- 固定使用 0.1 M 滴定剂。
- 不使用过冲后的动作遮罩、自动缩小最大体积或自动切换稀滴定剂。

因此，这个实验比较的是不同神经网络训练方法学习“加多少”的能力，不让外部安全层替神经网络决定体积。

## 对照设计

- 算法：PPO、A2C、REINFORCE。
- 初始化：归档的模仿策略权重，或显式独立随机权重。
- 五个独立训练种子：101、202、303、404、555。
- 每次训练约 25,000 次环境交互。
- 每个种子使用 5,000 项训练任务和另外生成的 1,000 项测试任务。
- 同一种子下，各算法使用相同的训练任务、测试任务、初始actor、奖励和预算。
- 模仿组与随机组的critic初始化保持配对；随机actor的生成不会改变后续训练采样的随机数序列。

## 怎么运行

1. 将整个文件夹放到另一台Windows设备上。
2. 先双击 `RUN_QUICK_TEST.cmd`。第一次运行会自动建立 `.venv` 并安装依赖。
3. 快速测试通过后，双击 `RUN_FULL.cmd`。
4. 如果设备已经正确安装支持CUDA的PyTorch，也可以使用 `RUN_FULL_CUDA.cmd`；为了结果环境更统一，默认建议运行CPU版。
5. 运行中断后可以再次双击同一个文件，已经完成且配置一致的条件会自动跳过。

首次安装PyTorch需要联网。完整实验包含30次训练，所需时间取决于CPU/GPU性能。

## 跑完后看什么

结果保存在 `results_full`：

- `RESULT_SUMMARY.md`：自动生成的主要结果和统计表。
- `aggregate_summary.csv`：各算法和初始化的五种子均值与样本标准差。
- `seed_summary.csv`：每次独立训练的结果。
- `paired_initialization_tests.csv`：随机初始化与模仿初始化的成对比较。
- `paired_algorithm_tests.csv`：PPO、A2C和REINFORCE之间的成对比较。
- `learning_curves.csv` 和 `learning_curves.svg`：正确按训练阶段对齐的五种子学习曲线。
- `task_results.csv`：全部30,000条测试任务结果。
- `RESULT_VALIDATION.json`：完整性、控制逻辑和初始化配对检查；应显示 `PASS`。
- `runs/*/final_model.pth`：30个最终模型。

把完整的 `results_full` 文件夹带回来即可分析。不要只带截图，因为统计检验需要任务级CSV。

## 解释边界

这不是神经网络独立选择酸/碱方向和体积的完整控制实验。它评价的是带统一方向规则的体积策略，与真实部署的1,000输出模型相对应。它也不同于旧的安全辅助环境，因为本实验没有过冲限幅和稀滴定剂自动切换。
