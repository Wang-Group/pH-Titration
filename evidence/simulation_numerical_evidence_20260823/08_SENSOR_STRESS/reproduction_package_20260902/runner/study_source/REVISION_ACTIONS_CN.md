# 本轮结果对应的论文修改与未完成事项

## 已由本轮正式计算支持

- 新 PF 外部规则消融：5 个种子 x 每种子 3000 个配对任务 x 3 个控制器，共 45000 行。完整 `hybrid_full` 成功率 95.36 +/- 0.59%，显著优于去掉过冲上限和 posterior-direct，因此教师应使用完整 PF 加控制逻辑。
- 教师数据：训练侧 15000 个候选任务，63728 个唯一状态；验证侧 2900 个候选任务，12827 个状态；质量筛选、方向平衡和覆盖缺口均有审计记录。
- 模仿学习：3 个训练种子，最终按独立验证选中种子 22，成功率 90.0%。
- PPO：5 个训练种子，每个至少 100000 次环境交互；学习曲线、独立验证选择、锁定测试和检查点哈希均已保存。
- 双网络锁定比较：预先按验证选中的 PPO 303 在 1000 个标称共同任务上为 93.4%，模仿为 89.1%，差 +4.30 个百分点，精确 McNemar p=8.91e-7；成功任务平均步数从 8.63 降至 5.68。
- 压力测试：PPO 303 相对模仿在 close-pKa 上 +6.33 点（p=0.00540），宽浓度上 +4.67 点（p=0.0201）。
- RL 独立干预审计：5 个评测种子 x 每条件每种子 500 任务，共 105000 行策略-任务结果。标称未见任务 +4.64 点，0.05 pH 传感器噪声 +12.96 点；0.70 响应滞后反而 -9.24 点；联合扰动主终点 +1.48 点且 p=0.261。因此只能写“特定条件下 PPO 有效”，不能写“普遍鲁棒”。
- 后验诊断：5 个种子 x 300 个任务，在 0/1/2/3/5/8/12 次观测和自然结束点统计完整曲线及参数。自然结束控制成功率 95.80 +/- 1.92%，但曲线 RMSE 1.1370 +/- 0.0523 pH、浓度误差 47.33 +/- 3.91%、K 准确率 46.07 +/- 2.55%。这证明控制成功不能等同于参数识别准确。
- PF 拟合分布：同一批 1500 个任务从先验到 12 次观测的 RMSE 均值由 1.3894 降至 1.1388 pH，中位数由 1.1334 降至 0.9643；五个种子的均值变化全部为负，跨种子变化 -0.2506 +/- 0.0453 pH，95% t 区间 [-0.3069, -0.1943]。但仅 60.0% 的任务净改善，主要收益集中于前 1-5 次观测，不能写成逐任务单调收敛。
- PF 困难子群：自然结束时酸向高于碱向（RMSE 1.399 vs 0.875），near 高于 far（1.426 vs 0.617），重叠 pKa 高于 separated（1.700 vs 1.127）。全曲线 RMSE 与最终控制误差仅弱相关（Spearman rho=0.157）。

## 论文中建议采用的准确表述

1. PF 是可变 K、联合浓度/pKa 的序贯重要性重采样粒子滤波器。
2. 当前高成功率属于“PF 后验 + 外部体积整形 + 过冲上限”的完整混合控制器。
3. 模仿网络和 PPO 网络完整决定 0.01-10.00 mL 加液体积，但酸/碱方向仍由共同外部规则决定。
4. PPO 相对模仿在锁定标称任务、close-pKa、宽浓度和较强传感器噪声下有显著改善，但对严重传感器响应滞后更差，联合扰动主终点不显著。
5. PF 可在后验参数尚未准确识别时实现有效控制；“可解释”应限定为结构化、可检查的不确定性表示，而不是已证明的真实化学参数恢复。
6. RMSE 的总体分布随观测改善且跨五个种子复现，但约 40% 任务没有更低的最终 RMSE；必须同时报告分布和任务内配对结果，不能只展示均值曲线。
