# Robust PF 外部规则、模仿学习、PPO 与后验准确度完整研究包

本包回答五个相互关联的问题：

1. 新的 `pf_pka_conc_variable_k` 粒子滤波器是否依赖外部加液体积控制逻辑。
2. 如果外部控制重要，使用效果最好的 PF 与控制逻辑作为教师后，模仿学习和 PPO 的效果如何。
3. 训练后选定的模仿网络与 PPO 网络在独立锁定任务上的表现如何。
4. PF 在 0、1、2、3、5、8、12 次观测和自然实验结束时，拟合曲线与真值有多相似，浓度、有效 pKa 数和 pKa 参数有多准确。
5. 在主模型测评之外，PPO 相对完全相同的模仿初始化是否在超出训练范围的执行器、滴定剂、传感器和响应滞后干预下表现出可重复的闭环改进。
6. 新 PF 的完整曲线 RMSE 分布如何随观测次数变化，这种变化能否跨随机种子复现，以及哪些化学任务最难拟合。

## 正式实验规模

- 外部规则消融：5 个独立种子，每种子 3000 个任务，每任务严格配对运行 3 个控制器，每个控制器 1000 个粒子。
- 教师数据：完整外部规则在正式消融中胜出后，使用 `hybrid_full` 生成至少 60000 个训练状态和 12000 个验证状态。
- 模仿学习：3 个独立训练种子，按独立验证任务选择模型。
- PPO：5 个独立训练种子，每种子 100000 次环境交互，检查点只按独立验证任务选择。
- 网络评价：1000 个标称锁定任务，以及 close-pKa、宽浓度压力测试。
- 后验诊断：5 个独立种子，每种子 300 个任务，共 1500 个任务；固定观测次数与自然停止点分开统计。
- PF 拟合分布：同一批 1500 个任务在 0、1、2、3、5、8、12 次观测严格配对；同时报告任务层面分布、五个种子层面的均值变化、阈值达标率、参数分布和困难子群。
- RL 有效性审计：5 个独立评测种子，每个种子、每种干预 500 个任务；所有 5 个 PPO 训练种子与模仿初始化使用严格配对任务和随机抽样。

所有控制器和网络使用 0.01 pH 分辨率的测量值决策，成功、严格成功、严重失败和最终误差使用未量化的真实化学 pH。动作体积为 0.01-10.00 mL。当前神经网络负责加液体积，酸/碱方向使用共同外部方向规则。

## 运行

GPU 设备优先双击：

1. `INSTALL_ENV_CUDA.cmd`
2. `RUN_COMPLETE_STUDY_CUDA.cmd`

仅检查安装和流程时运行 `RUN_COMPLETE_STUDY_QUICK.cmd`。快速结果不能用于论文结论。

完整流程支持 `--resume`。每个阶段只有生成独立完成标记后才会被跳过，配置不一致时拒绝复用旧结果。

## 主要输出

- `00_pf_ablation` 或指定的独立消融目录：外部规则的 5 x 3000 配对结果。
- `01_teacher_data`：教师任务、状态、质量与覆盖审计。
- `02_imitation`：3 个模仿种子、最佳检查点及验证结果。
- `03_ppo`：5 个 PPO 种子、学习曲线和锁定结果。
- `04_evaluation`：PF、模仿学习和所有 PPO 种子的统一评价。
- `05_posterior_diagnostics`：不同观测次数与自然结束时的曲线和后验参数准确度。
- `06_two_network_evaluation`：按验证集选定的模仿网络与 PPO 网络的直接配对测评。
- `07_rl_effectiveness`：同一初始化的 PPO 前后变化、未见干预、过冲恢复、全部训练种子复现性、配对检验和检查点哈希。
- `08_pf_fit_distributions`：RMSE 随步数的提琴图和阈值曲线、任务内配对变化、跨种子复现、后验参数分布、自然结束困难子群及拟合与控制终点关联。
- `TEACHER_SELECTION.json`：根据正式消融自动生成的教师选择证据。
- `PIPELINE_COMPLETE.json`：完整流程结束标记。

阅读结果时优先查看各目录内的 Markdown 摘要、`aggregate_*.csv`、任务级 CSV 和运行配置 JSON。
