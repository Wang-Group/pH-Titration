# Cu-SSA Job plot 复现审计

数据源：`job_experiment_data.csv`、`ph_adjustment_data.csv` 和 `uvvis_spectra.csv`。

## 原始数据一致性

- 11 个 400 nm 吸光度与原始 UV-Vis 光谱在 399.9859 nm 处的数值逐项一致。
- 每组终体积均等于 11.02 mL 初始混合体积加上 pH 调节记录中的累计加液量。
- 终点 pH 与逐步 pH 记录一致，范围为 4.17-4.22。

## 与三篇文档的数值核对

稀释校正按下式复现：

`A_corr = A_raw * V_final / 11.02`

当 Cu-rich 支线加入理论端点 `(0, 0)`，SSA-rich 支线加入理论端点 `(1, 0)`，并将 `X_SSA = 0.500` 的实测点同时纳入两侧回归时，可以复现文稿数值：

| 量 | 复现值 | 文稿报道 |
| --- | ---: | ---: |
| 实测最大值位置 | 0.500000 | 0.500 |
| Cu-rich `R^2` | 0.936839 | 0.937 |
| SSA-rich `R^2` | 0.952208 | 0.952 |
| 支线交点 `X_SSA` | 0.491635895 | 0.4916 / 0.492 |
| 交点响应 `A_fit` | 0.449671585 | 0.449672 |
| 等摩尔校正响应 | 0.401126017 | 0.401126 |
| `alpha` | 0.107957828 | 0.10796 |
| 终态单组分分析浓度 | 0.003890346 mol L^-1 | 0.003890 mol L^-1 |
| `K_app` | 19673.83 L mol^-1 | `1.97 * 10^4` L mol^-1 |
| `log10(K_app)` | 4.293889 | 4.294 |
| 与 3.295 的差 | 0.998889 | 0.999 |

因此，`Manuscript_revision_V9.docx`、`Supporting_Information_final_V9.docx` 和 `Response_V32.docx` 中的上述数值在同一拟合规则下彼此一致，也可由原始数据复现。

三篇文档中嵌入的 Job 图也与这套数据和支线拟合一致；图中延伸到 `X_SSA = 0` 和 `1` 的拟合线分别给出约 0.0494 和 0.0455 的截距，与加入理论零响应端点后的回归一致。但是两个理论端点未作为数据点显示，因此仍需在方法文字中明确说明。

## 需要补充说明的方法细节

现有文字只说对两侧支线作线性拟合，但没有明确说明加入了 `(0, 0)` 和 `(1, 0)` 两个理论零响应端点。不加这两个端点时，不能得到文稿报道的 `A_fit = 0.449672` 和 `K_app = 1.97 * 10^4`。

建议在 SI 和回复稿中增加一句：

> The Cu-rich and SSA-rich branch regressions included the theoretical zero-response endpoints at XSSA = 0 and 1, respectively, and the measured XSSA = 0.500 point was included in both branches.

## 方法敏感性

| 支线拟合规则 | 交点 `X_SSA` | `A_fit` | `K_app` (L mol^-1) | `log10(K_app)` |
| --- | ---: | ---: | ---: | ---: |
| 加理论端点，中心点纳入两支（文稿方法） | 0.491636 | 0.449672 | 19674 | 4.294 |
| 仅实测点，中心点纳入两支 | 0.491200 | 0.433854 | 41763 | 4.621 |
| 仅实测点，中心点不纳入支线 | 0.484206 | 0.469597 | 10328 | 4.014 |
| 加理论端点，中心点不纳入支线 | 0.486361 | 0.491585 | 6194 | 3.792 |

这些变体都将交点放在约 0.49，因此“测试条件下以 1:1 组成为主”的定性结论较稳定。但是交点高度和由此推导的 `K_app` 对拟合规则很敏感，所以它应继续被表述为依赖当前处理规则的近似表观条件常数，不应说成唯一或普适的热力学稳定常数。
